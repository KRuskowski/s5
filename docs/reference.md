## Configuration paths

Set inside a `configure` session: `set <path> <value>`, `delete <path>`, then `commit`. `<name>` marks a key you choose (a port, an interface, a VLAN id).

| Path | Type | Default | Description |
|---|---|---|---|
| `dns.primary` | ip | — | Primary DNS nameserver |
| `dns.secondary` | ip | — | Secondary DNS nameserver |
| `hostname` | string | — | Switch hostname |
| `igmp_snooping.enabled` | boolean | true | Prune multicast to ports that asked for it |
| `igmp_snooping.querier` | boolean | false | Send IGMP queries (needed with no router on the L2) |
| `interfaces.<name>.address` | cidr | — | Static address + prefix |
| `interfaces.<name>.dhcp` | boolean | false | Acquire the address via DHCP instead |
| `mac.aging_time` | integer [10..1000000] | 300 | Seconds before a learned MAC is forgotten |
| `mac.static.<name>.port` | string | — | Port the static entry points at |
| `mac.static.<name>.vlan` | integer [1..4094] | 1 | VLAN the static entry belongs to |
| `ntp.server` | string | — | NTP server hostname or IP |
| `poe.<name>.enabled` | boolean | true | PoE power delivery on this port (1-5) |
| `poe.<name>.power_limit_mw` | integer [0..30000] | — | Per-port power limit in milliwatts |
| `ports.<name>.duplex` | enum {auto, half, full} | auto | Duplex mode, or auto-negotiate |
| `ports.<name>.enabled` | boolean | true | Administrative port state (lan1..lan5, wan) |
| `ports.<name>.flow_control` | boolean | false | 802.3x pause frames |
| `ports.<name>.mtu` | integer [1280..9216] | 1500 | Maximum transmission unit |
| `ports.<name>.speed` | enum {auto, 10, 100, 1000} | auto | Link speed in Mbit/s, or auto-negotiate |
| `ports.<name>.vlan.<name>` | enum {tagged, untagged, pvid, untagged-pvid} | — | 802.1Q membership mode for this VID |

## Configuration lifecycle commands

| Command | Role | Description |
|---|---|---|
| `commit` | admin | Apply the candidate configuration |
| `commit confirmed <minutes>` | admin | Apply, then auto-revert unless confirmed in time |
| `configure` | admin | Enter configure mode and open a candidate session |
| `configure force` | admin | Take configure mode from another session, discarding its candidate |
| `confirm` | admin | Confirm a pending commit-confirmed (cancel auto-revert) |
| `delete <path>` | admin | Remove a candidate-config value at a schema path |
| `load factory` | admin | Load the shipped factory defaults into the candidate (commit to complete a factory reset) |
| `load merge <name>` | admin | Merge a saved configuration into the candidate |
| `load replace <name>` | admin | Replace the candidate with a saved configuration |
| `rollback candidate` | admin | Discard the candidate session |
| `rollback previous` | admin | Roll back to the previous commit |
| `rollback rescue` | admin | Restore the saved rescue configuration and commit it |
| `rollback to <id>` | admin | Re-apply a specific committed revision |
| `save <name>` | admin | Save the running configuration to a named file |
| `set <path> <value>` | admin | Set a candidate-config value at a schema path |
| `show commit <id>` | any | Show a single commit by id |
| `show commits` | any | List commit history |
| `show config [prefix]` | any | Show running configuration (optional prefix) |
| `show configs` | any | List saved configuration files |
| `show diff` | any | Show uncommitted candidate changes vs running (Junos: show \| compare) |
| `show schema` | any | List every configurable path with type + help |
